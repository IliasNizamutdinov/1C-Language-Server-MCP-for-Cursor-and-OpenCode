# Уведомления о сторонних компонентах

Этот репозиторий содержит собственный MCP-адаптер. Он не включает исходный код и двоичные сборки перечисленных ниже проектов. Адаптер запускает BSL Language Server отдельным процессом, если пользователь сам установил официальную сборку.

## BSL Language Server

- Проект: BSL Language Server
- Назначение в этом репозитории: разбор и диагностика кода 1С (BSL) и OneScript. Адаптер не реализует собственный парсер.
- Репозиторий: https://github.com/1c-syntax/bsl-language-server
- Документация: https://1c-syntax.github.io/bsl-language-server/
- Проверенный релиз: 1.0.7
- Страница релиза: https://github.com/1c-syntax/bsl-language-server/releases/tag/v1.0.7
- Файл сборки, который ожидается у пользователя: `bsl-language-server-1.0.7-exec.jar`
- Адрес загрузки: https://github.com/1c-syntax/bsl-language-server/releases/download/v1.0.7/bsl-language-server-1.0.7-exec.jar
- SHA256: `9f62765edd344d66456da24c906eaf623a03c56e90e5aafee466200100909f64`
- Лицензия: GNU Lesser General Public License версии 3 или любой более поздней версии (`LGPL-3.0-or-later`)
- Текст лицензии: https://github.com/1c-syntax/bsl-language-server/blob/v1.0.7/COPYING.md
- Авторское уведомление из исходного файла `AnalyzeCommand.java` релиза v1.0.7: Copyright (c) 2018-2026 Alexey Sosnoviy <labotamy@gmail.com>, Nikita Fedkin <nixel2007@gmail.com> and contributors
- SPDX-идентификатор в том же файле: `LGPL-3.0-or-later`

BSL Language Server разработан сообществом 1c-syntax и указанными авторами. Автор этого репозитория не является автором BSL Language Server.

Адаптер не является производной модификацией анализатора и не связывает его код со своим кодом. Пользователь получает сборку отдельно с официальной страницы релизов. Внутри этой сборки есть собственные уведомления о транзитивных компонентах анализатора; они распространяются вместе с официальным архивом или jar и здесь не копируются.

Обязанности LGPL для комбинированного произведения на этот репозиторий не переносятся как на распространение самой библиотеки: библиотека пользователю этим репозиторием не передаётся. Уведомление об использовании, ссылка на лицензию и указание авторов даны в этом файле и в `README.md`.

Параметр `sendErrors` в конфигурации, которую формирует адаптер, всегда устанавливается в `never`, чтобы режим анализа не предлагал отправку сообщений об ошибках разработчикам BSL Language Server.

## Python MCP SDK

Прямая зависимость адаптера — пакет `mcp`.

- Проверенная при разработке версия: 1.30.0
- Лицензия по метаданным пакета: MIT
- Ограничение в `pyproject.toml`: `mcp>=1.9,<2`
- Репозиторий: https://github.com/modelcontextprotocol/python-sdk

Пакет устанавливается пользователем через pip и в этот git-репозиторий не копируется.
