# Релизы

Лист версий адаптера `bsl-syntax`. Анализ выполняет BSL Language Server, в этой поставке проверена сборка 1.0.7.

## 0.2.0 — режим совместимости и типы методов

Ветка: `cursor/compatibility-and-types-4a63`.

- При проверке учитывается режим совместимости конфигурации. Источники: параметр `compatibility_mode`, переменная `BSL_MCP_COMPATIBILITY_MODE`, тег `CompatibilityMode` в `Configuration.xml` / `ConfigurationExtension.xml` / `Configuration.mdo`, затем `v8platform.targetVersion`.
- Версия передаётся в BSL Language Server. Для `8.3.10` вызов `ВопросАсинх` не проходит, для `8.5` проходит.
- Если режим не задан, ответ явно говорит, что различие 8.3 и 8.5 не учитывалось. Такой запуск не выглядит как успешная проверка нужной версии.
- Типы параметров и переменных процедур и функций: BSL Language Server 1.0.7 их не сверяет. Синтаксис `Параметр: Число` остаётся ошибкой разбора и на 8.3, и на 8.5. Аннотация `&Тип` разбирается, но не проверяет присваивания. В ответе есть поле `type_check`.

## Исправление требования к Java

Для `bsl-language-server-1.0.7-exec.jar` нужна Java 21 или любая более новая версия. Сборка скомпилирована в class-файл версии 65.0. Java 17 и более старые её не запускают и пишут `UnsupportedClassVersionError`. Контрольная сумма jar при этом может быть верной.

## 0.1.0 — первый выпуск

Ветка `main`, коммит `ac2994a`.

- MCP-инструменты `check_bsl_file`, `check_bsl_code`, `check_bsl_files`, `check_bsl_project`.
- Запуск BSL Language Server 1.0.7 в режиме `analyze`.
- Диагностика с файлом, строкой и столбцом.
- Проверка текста без записи в проект, ограничение путей и таймаут процесса.
